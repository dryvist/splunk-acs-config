# ACS configuration

Store ACS objects as TOML and reconcile them with live stacks using
`acs_config.py` and the pipeline template.

## Start

1. Copy `example/` to a configuration repository.
2. Set stack access variables in your pipeline.
3. Run `plan` and review the differences.

See the [wiki](wiki/Home.md) for setup, file format, commands, and troubleshooting.
