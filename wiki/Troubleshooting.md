# Troubleshooting

Each page below gives the symptom, the cause or check, and the verify step for one ACS or pull request error.

| Page | Symptom |
| --- | --- |
| [Authentication](/Troubleshooting/Authentication) | ACS returns 401 or 403. |
| [ACS allowlist](/Troubleshooting/ACS-allowlist) | An agent cannot reach ACS. |
| [Async timeout](/Troubleshooting/Async-timeout) | An ACS operation returns 202 and times out. |
| [Built-in roles](/Troubleshooting/Built-in-roles) | A built-in role cannot be edited. |
| [Pull request permission](/Troubleshooting/Pull-request-permission) | The pull step gets HTTP 403. |
| [Only live objects](/Troubleshooting/Only-live-objects) | A plan reports ONLY LIVE objects. |
